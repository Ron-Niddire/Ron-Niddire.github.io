The gable walls are treated as straight. The back and front stud walls follow these three measurements.

Chalk line

"Start of row 2, joint on stair walls" moves the rows so a joint runs across the ends of the stair walls, then puts the line on the front edge of row 1. "At the start of row 2" fits row 1 to the back wall instead. Either way the line is measured off the back wall. The front-corner boxes then fill in for you. "At a set distance" uses the front-left distance you type, measured square off the front wall, and the rows move so a joint sits on the line. The boards run parallel to the line. Leave the middle box empty to treat the front wall as straight. Fill it in once the line is struck and the plan shows where the bow is.

Boards

Covering width is the visible face once clicked together, not including the tongue. Check the pack label.

Stagger

"Use offcuts" starts each row with the piece cut off the end of the row before, so less goes in the skip. A new cut is only made when that piece would break the rules.
